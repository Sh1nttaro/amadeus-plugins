# amadeus-providers — свои провайдеры моделей в DSH

Отдельная страница настроек **«Провайдеры»**: подключить любой OpenAI-, Anthropic- или
Gemini-совместимый адрес (свой сервер, шлюз LiteLLM, OpenRouter), посмотреть, какие модели там есть,
включить нужные и увидеть по каждой контекст, возможности и цену.

Работает поверх штатного адаптера `llm-pi-ai`: пишет в его настройки (`providers`) и в хранилище
ключей DSH теми же вызовами, что и вкладка Models, поэтому обе вкладки видят одно и то же.

## Что умеет

- **Добавить подключение:** название, протокол (OpenAI Chat Completions / Responses, Anthropic
  Messages, Google Gemini), базовый URL, ключ (хранится в защищённом хранилище DSH под именем
  `<ИМЯ>_API_KEY`, в настройки не попадает).
- **«Проверить»:** опрашивает адрес и показывает все модели провайдера. Для LiteLLM читает
  `/model/info` (контекст, лимит вывода, возможности, цена), для OpenRouter — цены и контекст из
  `/models`, для Anthropic и Gemini — их родные списки. Ключ берётся из хранилища на стороне хоста и
  до страницы не доходит.
- **Шторка у каждой модели:** включена — модель появляется в выборе модели чата; выключена —
  убирается. У подключения должна оставаться хотя бы одна модель.
- **Контекст, вывод, вход (текст / картинки), инструменты, рассуждения, кэш, цена за 1M токенов.**
  Цену можно задать руками, если провайдер её не сообщает (она хранится только в плагине: в настройках
  DSH поля цены нет).
- **Изменить / Удалить** подключение; поиск и «только включённые» в длинных списках.

## Уровни рассуждения

Провайдер сообщает только «модель рассуждает или нет», но не список уровней, поэтому уровни хранятся в
настройках модели (`reasoningEfforts`). При включении рассуждающей модели плагин ставит стандартный набор
(выкл, низкое, среднее, высокое), чип рассуждений в строке модели меняет набор (выкл … максимум, «Не
рассуждает», «Сбросить»), а кнопка «Включить уровни» делает то же для уже включённых.

## Выбор модели в чате

Плагин заменяет штатный выбор модели в поле ввода (слот `conversation.input.model` с рангом −10): кнопка
«модель + уровень» → окошко с ползунком уровня → по клику на модель список моделей по провайдерам. Переключатель
командной работы DSH остаётся под ползунком. Если выбор не отрисуется, он сам снимается, и возвращается штатный.

## Файлы

| Файл | Что |
|---|---|
| `lib/probe.js` | опрос адреса и нормализация ответов (покрыт тестами) |
| `lib/index.js` | хост: маршруты `/amadeus-providers/probe`, `meta`, `log` |
| `lib/client.src.js` → `lib/client.js` | страница настроек; сборка `node build.cjs` подставляет общий CSS из live3D |
| `data.json` | что узнали проверки (создаётся сам, в git не входит) |

Тесты: `node --test test/probe.test.mjs`.

## Безопасность

Маршруты хоста умеют отправлять сохранённый ключ на адрес, поэтому их вызывает только эта страница:
нужен заголовок `x-amadeus-providers`, тело `application/json` и `Host: localhost` (чужая веб-страница
не сможет вызвать их из браузера, в том числе через DNS-rebinding).

## Установка

См. общую схему в корневом README: плагин копируется в `profiles\desktop\plugins\`, подключается
ссылкой в `node_modules` и записью в `dependencies` и `dsh.profile.bundles`.
